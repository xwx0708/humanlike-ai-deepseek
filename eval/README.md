# 长期对话对照评估

项目总评（[00-总纲/项目总评-2026-11-02.md](../00-总纲/项目总评-2026-11-02.md)）第三步：用一段模拟的长期聊天，比较"记忆系统"和"只带最近聊天记录"哪个记得更准、更少瞎编。

**我的设想**：用户 2026-11-08 同意方案和规模："可以，按这个规模"（3 周剧本、约 20 个问题，DeepSeek 不到 100 万 token，本地 Qwen 约 1 小时）。

## 怎么比（补充）

| 项 | 记忆组 | 对照组 |
|---|---|---|
| 记忆 | `DefaultMemoryService`（概率海），后台照真实规则运行：每分钟扫描、停顿后整理、对话中途分批、夜间合并，潜意识模型用 `.env` 里的（本地 Qwen） | `RecentWindowMemory`：只带最近的聊天记录 |
| 输入长度上限 | 上下文预算 常驻 1000 + 浮现 500 + 新鲜 2500 = 4000 token（部署是 3000 + 1500 + 8000，按比例缩小，见下） | 聊天记录最多 4000 token |
| 启动 | 上下文用到 5000 token 启动（部署默认 6 万，D43），之前和对照组一样带全部记录 | 一直带记录 |
| 工具 | `recall_memory`（D48） | 无 |
| 思考模型、人设、提示词组织 | 同一个（`.env` 的 THINKING_MODEL，和 AstrBot 里配的一样）；`Responder` 同一份代码 | 同左 |

- 剧本（`scenario.py`）：模拟用户林舟 21 天的 QQ 私聊，每天晚上 9 点一场，约 20 来回。17 件要记住的事（平淡 / 重要 / 动情）是手写的，其中 5 件后来变了（出院、搬家、拿到 offer、戒咖啡、和好）；其余闲聊由 DeepSeek 生成一次后存进 `data/script.json`，之后每次都用同一份。
- 20 个问题（`scenario.PROBES`）：回忆 12 个、改口（要答最新的）5 个、从没说过（看会不会瞎编）3 个，在当天对话最后问。两组问同样的问题，回答记进各自的记忆。
- 评分：DeepSeek 按要点判"对 / 部分对 / 不记得 / 错 / 瞎编"。报告里逐题列出两组原话，可以人工复核。
- 为什么缩小（偏离 #22）：生成的剧本 21 天只有约 1.9 万 token，按部署的 12500 上限，对照组几乎能看到全部记录，比不出差别。两组上限一起按比例缩小，让"总聊天量 : 预算"接近部署后聊几个月的情形；两组上限仍然相同。
- 数据都写在 `results/<时间>/`，不碰 `data/memory.db`，不影响正在运行的 QQ 机器人。

## 用法

```
python eval/scenario.py          # 生成剧本（已有就不重新生成；--regen 强制）
python eval/run.py               # 全量，约 1 小时
python eval/run.py --days 3 --start-tokens 2000   # 小规模试跑
```

## 局限

- 只有一份剧本、一个模拟用户，问题只有 20 个，结论是方向性的，不是统计显著的。
- 评分也由 DeepSeek 做，可能偏向它自己的说法；逐题原话要人工看一遍。
- 剧本里 AI 的话是事先写好的，不是思考模型当场说的；"像不像人"不在这次评估范围内，只测记得准不准。
- 浮现按概率，换随机种子结果会变；这里固定种子 7。
