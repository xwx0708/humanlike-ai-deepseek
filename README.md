# 类人 AI（humanlike-ai）

做一个"像人"的聊天 AI：它不靠把全部聊天记录塞进上下文来"记得"你，而是有一套会遗忘、会模糊、会自己想起来的记忆。

> 在聊天这个领域，一味追求更长的上下文是走错了路。没有人能在脑子里同时摊开 100 万字的上下文；但人的记忆里装着千万、亿万级别的"上下文"，只是不会同时拿出来。
> —— [愿景](00-总纲/愿景.md)

**状态：开发中，还不能稳定使用。** 记忆模块已完成并有测试；回应模块第一版已写好，能在 AstrBot 里加载，但接上 QQ 后的实际对话还没测过；情绪、行动模块还没开始。

## 它怎么"记得"

- **熟悉期**：刚开始用时，上下文就是普通的聊天记录。上下文用到上限的约 70% 时，一次性整理全部对话，建立记忆，之后进入运行期。
- **运行期**：每轮交给模型的不再是聊天记录，而是记忆系统给出的内容：
  - **人设**：由使用者写；
  - **常驻栏**：一直记得的事，比如关于你的事实、你要求记住的、反复提起的；
  - **浮现区**：此刻自己想起来的事，按概率冒头，说不说由模型看语境决定；
  - **新鲜记忆**：刚说过的话，强度几乎还是满的。
- **遗忘**：每段记忆按遗忘曲线衰减，情绪越强、越重要的忘得越慢，被想起时会加固。时间按"对话时的时间"走：聊天时比现实快，不聊天时几乎停止，三个月不来，回来时不会淡忘一切。
- **没有信息是彻底忘掉的**：遗忘只是移出记忆，原文留在档案里。你让它忘掉某件事时，由你选"彻底删除"还是"存进档案"；档案只有你要求时它才会去翻。
- **潜意识**：对话停顿后，本地小模型在后台切段、打分、把片段挂到事件线上、调整遗忘参数，夜里合并重复的事件线。

细节见 [01-记忆/README.md](01-记忆/README.md)，以及其中的[遗忘曲线](01-记忆/遗忘曲线.md)、[潜意识](01-记忆/潜意识.md)、[事件切分](01-记忆/事件切分.md)等文档。所有设计决定记在[决策日志](00-总纲/决策日志.md)。

## 组成

| 模块 | 对应人的什么 | 状态 |
|---|---|---|
| [记忆](01-记忆/README.md) | 长期记忆、遗忘、联想 | 已完成，有测试 |
| [回应](03-回应/README.md) | 有意识的思考与说话 | 第一版，未实测 |
| [情绪](02-情绪/README.md) | 情绪感知与情绪状态 | 未开始（记忆里的情绪分暂由切段模型一起打） |
| [行动](04-行动/README.md) | 手脚 | 第一版直接用 AstrBot 自带的 MCP |

两个模型可以随意换：

- **思考模型**负责当下的对话，任何 OpenAI 兼容接口都能用，默认 DeepSeek。
- **潜意识模型**负责后台整理，默认是本机 Ollama 上的 Qwen。

对话平台是 QQ：[NapCat](https://github.com/NapNeko/NapCatQQ) 登录 QQ 小号，经 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 接到本项目的插件。

## 安装（Docker 一键部署）

需要：Docker；本机装好 [Ollama](https://ollama.com) 并有显卡（潜意识模型约十几 GB）；一个思考模型的 API 密钥；一个 QQ 小号。

```bash
git clone https://github.com/xwx0708/humanlike-ai-deepseek.git
cd humanlike-ai-deepseek
cp .env.example .env            # 至少填 OWNER_QQ：陪的那个人的 QQ 号
ollama pull qwen3.8:27b-q4_K_M  # 和 .env 里的 SUBCONSCIOUS_MODEL 一致
docker compose up -d            # 下载并启动 NapCat、AstrBot 的官方镜像
```

然后：

1. 打开 `http://127.0.0.1:6185`（AstrBot），添加"OpenAI 兼容"的模型提供方，填地址、密钥、模型名。
2. 打开 `http://127.0.0.1:6099/webui`（NapCat），用 QQ 小号扫码登录。
3. 在 `data/persona.md` 写人设，改了立即生效。

完整步骤、手动部署和装好后要核对的事见 [03-回应/部署.md](03-回应/部署.md)。

NapCat、AstrBot 都在安装时从官方镜像下载，不随本仓库分发。

## 使用前请知悉

- **只陪一个人，不进群聊。** 只回复 `OWNER_QQ` 的私聊。
- **QQ 小号可能被风控或封号**：NapCat 不是 QQ 官方的机器人接口。请用不重要的小号。
- **对话内容会发给思考模型的服务商**；潜意识整理在本机进行。
- 更多见[使用说明与限制](00-总纲/使用说明与限制.md)。

## 开发

```bash
python -m venv .venv
.venv/Scripts/python -m pip install jieba pytest ruff   # Linux / Mac 用 .venv/bin/python
.venv/Scripts/python -m pytest -q          # 默认不调用真实模型
.venv/Scripts/python -m pytest -m live     # 真实调用 DeepSeek 和本地 Qwen（会产生少量费用）
.venv/Scripts/python -m ruff check src tests
```

- 代码规范见 [00-总纲/代码规范.md](00-总纲/代码规范.md)，模块之间的接口见[接口约定](00-总纲/接口约定.md)。
- 记忆的可视化页面：`python 01-记忆/可视化/serve.py`，打开 `http://127.0.0.1:8790`。
- 这个项目由多个 Claude 对话分工完成，彼此通过仓库里的文件协作，规则见 [CLAUDE.md](CLAUDE.md)。文档里"我的设想"是作者的原意，"补充"是讨论中加入的内容。
