# 部署：NapCat + AstrBot + 本项目插件

> 2026-10-28 由总纲对话起草。AstrBot、NapCat 的具体界面以它们的官方文档为准（docs.astrbot.app、NapCat 文档）；
> 插件按 2026-10-28 的 AstrBot 文档和源码写，**还没在真正的 AstrBot 里跑过**，第一次装好后要实测（见末尾"装好后要核对"）。
> 风险和限制见 [使用说明与限制](../00-总纲/使用说明与限制.md)。

## 链路

```
QQ 小号 ⇄ NapCat ──反向 WebSocket（端口 6199）──▶ AstrBot ──▶ 插件 astrbot_plugin_humanlike ──▶ 本项目（记忆、回应）
                                                    └─ 思考模型：AstrBot 里配置的 OpenAI 兼容提供方
本项目 .env ──▶ 潜意识模型：本机 Ollama 上的 Qwen
```

## 步骤

1. **NapCat**：安装后用 QQ 小号登录。在网络配置里新建"WebSocket 客户端"（反向 WS），地址 `ws://127.0.0.1:6199/ws`。
2. **AstrBot**：安装并打开管理网页。
   - 消息平台：添加 OneBot v11（aiocqhttp），反向 WebSocket 端口 6199，和 NapCat 对上。
   - 模型提供方：添加"OpenAI 兼容"类型，填 API 地址、密钥、模型名（D28：不限于 DeepSeek），设为当前使用的模型。
3. **插件**：把本项目的 `src/response/astrbot_plugin` 文件夹链接进 AstrBot 的插件目录（用目录链接而不是复制，改代码立即生效）。在管理员 PowerShell 里：
   ```
   New-Item -ItemType Junction -Path "<AstrBot 目录>\data\plugins\astrbot_plugin_humanlike" -Target "E:\ai工程\src\response\astrbot_plugin"
   ```
   AstrBot 的 Python 环境里要装 jieba（插件目录的 `requirements.txt`，AstrBot 一般会自动装）。
4. **插件配置**（AstrBot 网页 → 插件 → 配置）：`owner_qq` 填你的 QQ 号（只回复这个号，D29）；`project_root` 一般留空。
5. **人设**：写在 `E:\ai工程\data\persona.md`（暂定位置，不进版本库）。每轮重新读，改了立即生效。
6. **本项目 `.env`**：潜意识模型（Ollama 上的 Qwen）照旧；`THINKING_CONTEXT_LIMIT` 改成 AstrBot 里那个模型的上下文上限（换模型时两边都要改）。Ollama 要开着。

## 装好后要核对

- 私聊发一句话，AI 能回；别的 QQ 号私聊、群里 @ 它，都不回。
- `data/memory.db` 里有消息（可视化页面能看到）。
- 熟悉期：AI 能接上前面所有的话。日志里没有"后台任务出错"。
- AstrBot 里配置一个 MCP 工具，让 AI 用一下，确认工具调用能跑通（插件用 `tool_loop_agent`）。
- `tool_loop_agent` 的 `contexts` 参数文档写的是 Message 对象，插件传的是字典（`text_chat` 接受字典）；如果熟悉期报错，要改成 Message。
- 模型回报的用量（`resp.usage`）能拿到，熟悉期 70% 的判断用的是它。
