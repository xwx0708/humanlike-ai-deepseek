# 部署：NapCat + AstrBot + 本项目插件

> 2026-10-28 由总纲对话起草。一键部署用 Docker Compose（D32）。AstrBot、NapCat 的具体界面以官方文档为准（docs.astrbot.app、NapCat 文档）。
> 风险和限制见 [使用说明与限制](../00-总纲/使用说明与限制.md)。

## 链路

```
QQ 小号 ⇄ NapCat 容器 ──反向 WebSocket──▶ AstrBot 容器 ──▶ 插件 astrbot_plugin_humanlike ──▶ 本项目（记忆、回应）
                                              └─ 思考模型：AstrBot 里配置的 OpenAI 兼容提供方
宿主机 Ollama ◀── 潜意识模型（本地 Qwen，用显卡）
```

NapCat、AstrBot 都用官方镜像（`mlikiowa/napcat-docker`、`soulter/astrbot`），安装时从网上下载，不放进本仓库：
NapCat 不允许未经授权基于它的代码开发、也没有明确允许再分发；QQ 本身是腾讯的程序。

## 一键部署（推荐，D32）

需要：Docker（Windows / Mac 装 Docker Desktop）；宿主机装好 Ollama 并下载潜意识模型。

1. 拉代码，进入项目文件夹。
2. 复制 `.env.example` 为 `.env`，至少填 `OWNER_QQ`（陪的那个人的 QQ 号）。思考模型不在这里填，见第 5 步。
3. 宿主机下载潜意识模型（约十几 GB，要有显卡）：`ollama pull qwen3.8:27b-q4_K_M`（模型名和 `.env` 里的 `SUBCONSCIOUS_MODEL` 一致）。
4. 启动：`docker compose up -d`。第一次会下载两个镜像。
5. 打开 `http://127.0.0.1:6185`（AstrBot 网页），添加"OpenAI 兼容"类型的模型提供方，填 API 地址、密钥、模型名，设为当前使用的模型（D28）。
   AstrBot 网页的默认账号密码见 AstrBot 文档；第一次登录后请修改。
6. 打开 `http://127.0.0.1:6099/webui`（NapCat 网页），用 QQ 小号扫码登录。NapCat 已经自动配置好连到 AstrBot。
7. 写人设：`data/persona.md`（暂定位置，不进版本库），改了立即生效。

   不想从头写的话，设置页"人设 → 人设库…"里列了这些来源（都是给 AI 聊天扮演用的，不是 agent 工作流），挑一个复制进来再按需修改：
   - 中文：[AstrBot 人格市场](https://astrbot.app/market)、[PlexPt/awesome-chatgpt-prompts-zh](https://github.com/PlexPt/awesome-chatgpt-prompts-zh)（64k ⭐）、[momozi1996/awesome-ai-persona-skills](https://github.com/momozi1996/awesome-ai-persona-skills)（1k ⭐）、[mrqy1/astrbot-persona](https://github.com/mrqy1/astrbot-persona)（模板）、[hitikem/qqbot-personas](https://github.com/hitikem/qqbot-personas)（含蓝鲸娘）
   - 英文：[Chub.ai / CharacterHub](https://www.characterhub.org)（含成人向，自行甄别）、[f/awesome-chatgpt-prompts](https://github.com/f/awesome-chatgpt-prompts)、[teknium1/character-cards](https://github.com/teknium1/character-cards)、[aicharactercards.com](https://aicharactercards.com)

   SillyTavern 格式的角色卡是 PNG / JSON，把 description / personality 的文字复制进来即可。喜欢的话，建议给原作者点点 ⭐。

8. 换思考模型时，同时把 `.env` 里的 `THINKING_CONTEXT_LIMIT` 改成新模型的上下文上限。

设置页：`http://127.0.0.1:8791`（D40），所有参数、功能开关、关键词、数据文件夹都在这里改，改完 `docker compose restart astrbot` 生效。不用 Docker 时运行 `python -m settings_page`（在 `src` 目录下，或把 `src` 加进 PYTHONPATH）。

数据都在项目的 `data/` 下（可在设置页改）：`memory.db`（记忆）、`astrbot/`（AstrBot 的配置）、`napcat/`（QQ 登录状态）。备份就复制 `data/`。
更新镜像：`docker compose pull && docker compose build --pull && docker compose up -d`。

## 不用 AstrBot：命令行平台（D44）

不想接 QQ、只想在终端里聊：在 `src` 目录下运行 `python -m response.cli`（或把 `src` 加进 PYTHONPATH）。
思考模型用 `.env` 里的 `THINKING_PROVIDER` / `THINKING_MODEL`（AstrBot 部署时这两项不起作用）；记忆、人设、后台整理和插件一样。
没有工具调用、联网搜索和看图——那些是 AstrBot 提供的。平台接口在 `src/contracts/platform.py`，接别的框架照它实现。

## 手动部署（不用 Docker）

1. NapCat：安装后用 QQ 小号登录，网络配置里新建"WebSocket 客户端"（反向 WS），地址 `ws://127.0.0.1:6199/ws`。
2. AstrBot：按官方文档安装。消息平台添加 OneBot v11（aiocqhttp），反向 WebSocket 端口 6199；模型提供方同上第 5 步。
3. 插件：把 `src/response/astrbot_plugin` 用目录链接放进 AstrBot 的插件目录（管理员 PowerShell）：
   ```
   New-Item -ItemType Junction -Path "<AstrBot 目录>\data\plugins\astrbot_plugin_humanlike" -Target "<本项目>\src\response\astrbot_plugin"
   ```
   AstrBot 的 Python 环境里要装 jieba。插件配置里填 `owner_qq`；`project_root` 一般留空。
4. 人设、`.env`、Ollama 同上。

## 装好后要核对

已验证：
- 2026-10-28，本机 Docker：镜像能构建，AstrBot 能加载插件、无报错；镜像里的 AstrBot 有插件用到的全部接口（`tool_loop_agent` 也接受字典形式的上下文）。
- 2026-10-29，接上 QQ 实测（AstrBot v4.29.3）：主号私聊小号"你好"，约 1.4 秒后小d 回复；消息和回复都存进了 `data/memory.db`；模型回报的用量能拿到（`context_used` = 212）。别的号发来的消息不回（OWNER_QQ 设错时验证到的）。

实测时踩过的坑：
- `OWNER_QQ` 填的是**你自己的**QQ 号（陪的那个人），不是机器人登录的小号。
- AstrBot 首次登录的密码只在第一次启动时打印在日志里，之后只存散列值。忘了的话停掉 astrbot，把 `data/astrbot/cmd_config.json` 移走再启动，会重新生成。
- AstrBot 的欢迎引导可能默认建一个"QQ 官方机器人"平台；用 NapCat 时要另建 OneBot v11 平台（端口 6199），把官方的关掉。

还没验证的：

- 群里 @ 它不回。
- 熟悉期多聊几句后，AI 能接上前面所有的话；日志里没有"后台任务出错"。
- AstrBot 里配置一个 MCP 工具，让 AI 用一下，确认工具调用能跑通（插件用 `tool_loop_agent`）。
- 上下文用到约 70% 后记忆系统启动，之后 AI 还接得上话（要聊很久才会到）。
