# 记忆可视化

用 3D 力导向图显示记忆模块的工作过程，常驻在副屏上，文件一改动就自动刷新。

## 打开

双击 `打开副屏.bat`（或运行 `python open_on_second_screen.py [页面]`，默认 `demo.html`）。它会：

1. 如果后台服务器没在运行，就启动 `serve.py`（端口 8790，只监听本机，无窗口）；
2. 用单独的 Edge 配置打开一个无地址栏的窗口，移到副屏并最大化。窗口已经开着时，只把它移回副屏。

电脑重启后服务器不会自动运行，再双击一次即可。

## 自动刷新

`serve.py` 每 0.3 秒检查本文件夹里的文件，有改动就通知所有打开的页面刷新。刷新脚本由服务器注入每个 html 页面，页面本身不用写。

注意：刷新会重置视角。以后图上显示的是模拟器的实时数据时，改成只更新数据、不刷新整页。

## 文件

| 文件 | 作用 |
|---|---|
| `demo.html` | 演示页（假数据） |
| `serve.py` | 带自动刷新的本地服务器 |
| `open_on_second_screen.py`、`打开副屏.bat` | 启动服务器，并在副屏打开窗口 |
| `vendor/` | 第三方库 3d-force-graph，来源见其中的 README |
