# 潜意识

> 状态：草案 v1（2026-10-27）。三个提示词、存储和整理流程已实现，见 [存储与提示词.md](存储与提示词.md)。

## 定位

**我的设想**：潜意识要负责切段和修改函数参数。

**补充**：潜意识在后台运行，不参与对话，也不直接和用户说话。它由两部分组成：
- **Python**：按固定公式执行衰减、加固、概率抽样、阈值判断，以及实时规则。
- **本地小模型**：只做需要理解语义的判断，输出结构化结果，经 Python 校验后才写入。

对应人脑：巩固和遗忘主要在后台完成（睡眠、走神时），不占用有意识的思考。

## 职责一：切段

方案见 [事件切分.md](事件切分.md)。

| 步骤 | 谁做 | 什么时候 |
|---|---|---|
| 标候选边界 | Python 规则 | 每条消息进来时 |
| 确认片段、起标题、调用情绪模块打分 | 小模型 | 对话停顿时 |
| 连成事件线 | 硬规则筛候选（最多 20 条）+ Qwen 判断归属 | 片段确定后 |

**分工原则**（决策 D10）：系统不使用嵌入模型。需要理解语义的判断（话题有没有变、属于哪条事件线）由潜意识模型 Qwen 做；数值计算由硬公式做（遗忘曲线等函数），它们的参数由 Qwen 修改。

## 职责二：修改函数参数

遗忘曲线的公式结构固定不变（见 [遗忘曲线.md](遗忘曲线.md)），潜意识只能修改其中的参数。

**补充：三层参数**

| 层级 | 改什么 | 例子 |
|---|---|---|
| 单条记忆 | 这条记忆的调整系数 $M$（进而改变半衰期）、与其他记忆的关联 | 用户说"我妈住院了"，把半年前"我妈最近老咳嗽"的半衰期拉长，并连到同一条事件线 |
| 类别 | 某一类话题整体忘得快一些或慢一些 | 用户反复提工作压力，"工作"类整体变慢 |
| 全局 | 五个半衰期旋钮、遗忘线、温度、扫描速度 | 见下方"待定" |

**流程**：新片段确定 → 按事件线候选规则找相关旧记忆 → 小模型输出结构化调整 → Python 校验、限幅后写入 → 记录日志。

**护栏**
- 只能改参数，不能改公式结构。
- 限幅：单条记忆单次最多 3 倍、累积最多 5 倍（已在 `src/memory/forgetting.py` 的 `clamp_adjustment` 中实现）。类别层的限幅待定。
- 全局参数：**我的设想**是允许潜意识自己改，但要窄幅、慢速、留日志。具体数值（补充，可再调）已在 `src/memory/tuning.py` 中实现：

  | 要求 | 规则 |
  |---|---|
  | 窄幅 | 单次最多变化 ±10%；始终保持在默认值的 1/1.5～1.5 倍之间（例如基础半衰期只能在 4.7～10.5 天之间） |
  | 慢速 | 同一个参数两次修改至少间隔 7 天；不同参数互不影响 |
  | 留日志 | 每次请求都记一条：参数名、时间、原值、请求值、实际采用值、是否生效、理由、护栏说明。**被拒绝的请求也记** |

  可以改的全局参数：基础半衰期、情绪放大、重要性放大、回忆加固、首尾加成、遗忘线。**小模型调整自身上限的两个参数不在其中**，避免它给自己松绑。温度和扫描速度属于扫描器，等扫描器实现后再接入这套护栏。
- 每次调整都写日志：改了什么、从多少改到多少、理由、依据哪个片段。日志可以对照档案原文复查，也可以回滚。

## 职责三：遗忘之后的整理

沿用设想文档"遗忘之后：归类、删除、模糊化"一节：强度低于遗忘线的片段，由潜意识归类、删减、模糊化，原文移入档案，留下残影；"一场对话"的摘要随子片段的遗忘重新概括。

## 什么时候运行

- 实时规则：每条消息进来时，只用 Python，不调用模型。
- 其余工作：对话停顿或空闲时批量运行，避免边读边改。
