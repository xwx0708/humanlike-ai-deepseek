# 愿景

> 状态：草案 v0（2026-10-27）。根据用户目前的说法整理，待用户确认、补充。

## 目标

做一个"像人"的聊天 AI。

## 出发点

**我的设想**
- 在聊天这个领域，一味追求更长的上下文是走错了路。没有人能在脑子里同时摊开 100 万字的上下文；但人的记忆里装着千万、亿万级别的"上下文"，只是不会同时拿出来。
- 要像人，就不能只有记忆。还要有情绪、有回应、能做事。人有真实的手脚，AI 也会有手脚，只不过它的手脚是 MCP 协议这类工具接口。

## 组成（暂定）

| 模块 | 对应人的什么 | 一句话 |
|---|---|---|
| 记忆 | 长期记忆、遗忘、联想 | 会遗忘、会模糊、会自己浮现的记忆系统 |
| 情绪 | 情绪感知与情绪状态 | 判断事件对用户有多大分量，形成情绪基线；以后可能有 AI 自身的情绪 |
| 回应 | 有意识的思考与说话 | 当下的对话：理解、组织语言、决定说什么、用什么语气 |
| 行动 | 手脚 | 通过 MCP 等工具真正做事，并把做过的事记住 |

用户提到组成"等等"，所以以后还可能增加模块。

## 待用户确认

- 产品定位：更偏情感陪伴，还是陪伴和工具兼顾？记忆文档里提到，这会影响"会遗忘"这一点是否合适。
- 是否有第一阶段的最小目标，比如先做一个只有"记忆 + 回应"的原型？
