# 代码规范

> 状态：草案 v0（2026-10-27），由总纲对话起草，待用户确认。目前还没有代码，这里先定会影响多个模块协作的规则，细节等写代码时再补。

## 基础

- 语言：Python 3.12（本机已安装）。
- 一个项目、一个虚拟环境：根目录的 `pyproject.toml` 和 `.venv/`，归总纲对话管理。某个模块需要新的依赖时，写进 `对外需求.md`。
- 格式化和检查用 `ruff`（`ruff format`、`ruff check`），测试用 `pytest`。
- 标识符用英文，与 [术语表](术语表.md) 的英文标识一致；注释和文档字符串可以用中文。
- 函数签名写类型标注。

## 目录

```
src/
  contracts/   模块之间交换的数据结构和接口（总纲对话负责）
  llm/         模型调用的实现：DeepSeek、Ollama、FakeModel（总纲对话负责）
  memory/      记忆模块
  emotion/     情绪模块
  response/    回应模块
  action/      行动模块
tests/
  memory/ emotion/ response/ action/
```

## 模块之间的规矩（最重要）

1. **模块之间只通过 `src/contracts/` 里定义的数据结构和接口交流**，不导入别的模块的内部实现。这样每个对话都能独立修改自己的模块，不会把别人的弄坏。
2. **时间要可注入**：凡是用到"现在几点"的代码（衰减、基线更新、扫描），都从传入的时钟对象取时间，不直接调用 `datetime.now()`。这样才能用模拟时间几秒钟跑完"半年的对话"。
3. **随机要可注入**：概率抽样使用传入的随机数生成器，测试时固定随机种子，保证可复现。
4. **模型调用要可替换**：调用大模型或小模型都经过 `contracts.llm.ChatModel`（见[接口约定](接口约定.md)），以便在 API 和本地模型之间切换；普通测试一律用 `llm.FakeModel`，不联网。
5. **真实调用模型的测试标记为 `live`**：默认 `pytest` 不运行它们，需要时用 `pytest -m live` 手动运行（DeepSeek 会产生少量费用，Qwen 首次加载约 1.5 分钟）。
6. **可调参数放配置，不写死**：半衰期旋钮、温度、扫描速度、遗忘线等放在配置文件里，方便调参和对比实验。

## 数据与安全

- 用户数据（记忆库、档案、情绪档案）放在 `data/`，不进版本库。
- API 密钥放在 `.env`，不进版本库，也不写进代码或文档。

## 提交

- 提交信息以模块开头，例如 `[记忆] 实现扫描器衰减`、`[总纲] 更新接口约定`。
- 一次提交只改自己负责的区域。
