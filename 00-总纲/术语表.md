# 术语表

> 各模块文档和代码以这里的定义为准。新增或修改术语，通过 `对外需求.md` 提请总纲对话处理。

| 术语 | 英文标识 | 定义 |
|---|---|---|
| 当下 | — | 上下文窗口里的内容，相当于人的工作记忆 |
| 非当下 / 概率海 | probability sea | 长期记忆库。每条记忆以某个强度存在，以某个概率被想起 |
| 事件 | event | 一段围绕同一件事的连续内容，是打分和记忆的基本单位 |
| 唤醒度 | arousal | 情绪有多强烈，0～1，决定记得牢不牢 |
| 效价 | valence | 情绪的正负，-1～1，只影响浮现概率，不影响遗忘速度 |
| 重要性 | importance | 与情绪无关的"不能忘"，例如过敏、家人名字 |
| 强度 | strength | 一条记忆当前的强弱，刚记下时为满值，随时间衰减 |
| 半衰期 | half_life | 强度衰减到一半所需的时间 |
| 遗忘线 | forget_line | 强度低于这条线就算被遗忘（约为满值的 1/10） |
| 回忆加固 | reinforcement | 记忆被想起后半衰期变长 |
| 启动加成 | priming | 当下话题按相似度给相关记忆增加的浮现分 |
| 温度 | temperature | 控制浮现概率分布的平坦程度：低温为专注，高温为放空 |
| 浮现区 | surface buffer | 容量 3～5 条，存放"自己冒头"的记忆，供思考模型查看 |
| 扫描器 | scanner | 后台按分区轮流计算衰减和浮现的程序 |
| 潜意识 | subconscious | 后台维护记忆库的部分：Python 执行公式，小模型调整系数 |
| 思考模型 | thinking model | 负责当下对话和推理的模型，归回应模块 |
| 档案 | archive | 被遗忘记忆的原文存放处，平时碰不到 |
| 残影 | trace | 遗忘后留在概率海里的极简概括，带指向档案的链接 |
| 用户画像 | user profile | 名字、关系等稳定事实，只能合并、不能改写，不参与遗忘 |
| 长期基线 | long-term baseline | 以月计的情绪基准，代表性格，用来计算相对情绪 |
| 短期心情 | short-term mood | 以天计的近况，不直接参与相减 |
| 熟悉期 / 启动 / 运行期 | — | 系统生命周期的三个阶段 |
